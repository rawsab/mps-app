Every staff member is either a **coach** or an **administrator**. Both use the same workspace. Administrators can also change client records and a few workspace settings.

## The two roles

- **Coach**: works with the clients assigned to them. Builds programs, runs meetings, records attendance and payments.
- **Administrator**: does everything a coach does, for every client. Also adds clients, sends invitations, manages services and sets default prices.

Roles are set outside the app, by the person who runs your workspace. You can't change your own role. Ask them if yours needs to change.

## Which clients you see

- A coach sees the clients assigned to them. A client can have more than one coach.
- An administrator sees every client.

Each client has one **primary coach**. Their meetings are on the primary coach's calendar, in the primary coach's time zone, and use the primary coach's open times.

### Transferring a client

An administrator can move a client to another coach.

1. On the Clients page, right-click the client's row. With a keyboard, move to the client's name and press the menu key.
2. Select **Transfer client**.
3. Choose the new coach and select **Transfer client**. Administrators are marked "(admin)" in the list.

The new coach takes over as primary coach, with the client's upcoming sessions and meetings. Other coaches assigned to the client keep their access.

## What each role can do

| Task | Coach | Administrator |
| --- | --- | --- |
| See clients | Assigned clients | Every client |
| Add a client | No | Yes |
| Send or resend an invitation | No | Yes |
| Disable or reactivate a client's access | No | Yes |
| Transfer a client to another coach | No | Yes |
| Add, pause, resume, end or archive a service | No | Yes |
| Delete an archived service | No | Yes |
| Accept or reject a service request | Yes | Yes |
| Build and edit programs | Yes | Yes |
| Publish, archive and restore programs | If allowed for that client | Yes |
| Delete an archived program permanently | No | Yes |
| Correct nutrition entries | Yes | Yes |
| Schedule meetings and answer requests | Yes | Yes |
| Record attendance | Yes | Yes |
| Set your own availability and time off | Yes | Yes |
| Record payments, charges and credits | Yes | Yes |
| Set a client's own prices | Yes | Yes |
| Set the default prices | No | Yes |

For a coach, Yes means for the clients assigned to them. For an administrator, it means for every client.

<Callout tone="note" title="Publishing">
A coach can publish a client's programs only if they have been allowed to for that client. If **Publish** is refused, ask an administrator.
</Callout>

## What clients can do

Clients see only their own records. They never see staff notes, other clients, or staff-only notes on meetings, payments and time off. See What clients see in Help.
